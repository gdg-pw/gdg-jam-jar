    Wrzuć na GitHub Pages

    1. Zaloguj się na GitHubie.
    2. Kliknij New repository, nadaj nazwę (np. portfolio), ustaw Public, zaznacz Add README i utwórz.
    3. Add file → Upload files, przeciągnij pliki strony i kliknij Commit changes. Plik index.html musi leżeć w głównym folderze.
    4. Settings → Pages: Source Deploy from a branch, branch main, folder / (root), Save.
    5. Po 1-2 minutach strona działa pod https://twoj-nick.github.io/portfolio/. Ten link wrzucasz do galerii.

    Działa wszystko, co jest zwykłymi plikami: HTML, CSS, JS, obrazki. Projekty wymagające budowania (np. React z Vite) nie ruszą bez dodatkowej konfiguracji. Wielkość liter w nazwach plików ma znaczenie: Style.css to nie style.css.
